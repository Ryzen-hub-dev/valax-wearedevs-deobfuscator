Protected-Code Recovery & Structural Analysis

Valax Source Recovery is an automated reverse-engineering engine for protected Lua and Luau code. It performs AST analysis, constant propagation, custom string pool decoding, and control-flow graph (CFG) flattening reversal to restore readable, structured source code.

Recovery Tiers & Admission Criteria

Tier Designation Admission Criteria & Verification Scope
L5-W Complete Structural Recovery Dispatcher fully eliminated (0 residual states), complete string pool resolution, syntax-valid Lua 5.1 roundtrip.
L4 Partial Control-Flow Recovery Core dispatch tree analyzed, high-volume residual states documented (e.g. 427 physical / 48 reachable states), source structured.
L3 Static Normalization String extraction and arithmetic constant folding without full control flow de-flattening.
L1-L2 Lexical / Structural Baseline AST validation and syntactic formatting baseline.

Isolated Containerized Execution Model

Every deobfuscation job executes inside an ephemeral, hardened Linux container managed by the Product Gateway and Redis queue:

  • Network Isolation: Zero outbound/inbound network interfaces (--network none).
  • Read-Only Filesystem: Root filesystem is strictly read-only with temporary RAM tmpfs mounts.
  • Privilege Drop: Executes as non-root user (uid 1000) with all Linux capabilities dropped (--cap-drop ALL, no-new-privileges:true).
  • Resource Constraints: Hard limits on CPU quota (1.0 CPU), memory bounds (512MB), and PID concurrency (128 PIDs).
