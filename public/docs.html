Workspace • Documentation • Status

Recovery Levels

  • L0 - Parsed: Lexical and syntax analysis complete, concrete AST generated.
  • L1 - Constants Normalized: Constant arithmetic, logical, and unary operations folded into simple literals.
  • L2 - Strings Recovered: Encoded string tables, custom alphabets, byte escapes, and index lookups resolved in-place.
  • L3 - Runtime Simplified: Standard library builtin aliases and environment lookups normalized.
  • L4 - Control Flow Recovered: Flattened state machine dispatchers converted into structured CFGs and control statements.
  • L5 - High-Level Source Reconstructed: Dead branches removed, redundant assignments collapsed, idiomatic Lua code emitted.

CLI Usage

node ./bin/valax.js input.lua --output result.lua --report report.json --stage L5

Discord Slash Command Integration

The /valax-recover slash command accepts Lua/Luau script attachments and returns a diagnostic embed with the recovered .lua file attached.
